📘 SupremeRP — LSPD Bodycam & Radio Commands

A clean, fast, single-page command reference for LSPD personnel.
Made by: Varun Vashisth (00)

📌 Overview

This website provides a structured list of LSPD bodycam, drone, evidence, and department radio commands.
The UI includes search, expand/collapse, copy buttons, and a clean blue LSPD-themed interface with the official logo.

Perfect for:

LSPD officers

Training & onboarding

Quick-copy roleplay commands

SupremeRP, FiveM, RageMP, or RP communities

✨ Features

✔ Full blue LSPD-style UI
✔ Built entirely in HTML + CSS + JavaScript
✔ One-page lightweight design
✔ Fast search filter
✔ Per-command Copy button
✔ Per-section Copy All button
✔ Expand/Collapse all
✔ Mobile responsive
✔ Custom logo support

📁 Project Structure
supremerp-commands/
 ├── index.html
 └── lspd-logo.jpg      ← Place your LSPD logo here


Ensure the logo file name is exactly: lspd-logo.jpg

🛠 How to Run Locally
Option A — VSCode Live Server (Recommended)

Install the Live Server extension in VSCode.

Right-click index.html → Open with Live Server.

Site opens at:

http://127.0.0.1:5500/

Option B — Run directly

Just open index.html in any browser.

🌍 Deploy & Host Online (Free)
1️⃣ Netlify (Drag & Drop — easiest)

Visit: https://app.netlify.com/drop

Drag the project folder (with index.html + logo).

Netlify gives you a live .netlify.app URL instantly.

2️⃣ GitHub Pages

Create a GitHub repository

Upload the project files

Go to:
Settings → Pages

Select Branch: main → Folder: / (root)

Click Save → Your URL becomes:

https://<username>.github.io/<repository>/

3️⃣ Vercel (Best for auto-deploy)

Login at https://vercel.com

Import your GitHub repo

Hit Deploy

Vercel hosts it automatically with every commit

🖼 Customizing Logo
